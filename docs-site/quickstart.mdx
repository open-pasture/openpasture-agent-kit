# Quickstart

Get a local farm running and make a first decision in a few minutes. Everything
here runs offline: land reports come from fixtures and collars are simulated.

## Requirements

- Python 3.11+
- An LLM provider key for your agent runtime
- Optional: Hermes for the Hermes adapter
- Optional: `FIRECRAWL_API_KEY` for real Alexandria land reports and knowledge,
  and for web knowledge ingestion

## Install

<Steps>
  <Step title="Install Hermes (optional)">
    Only needed if you plan to use the Hermes adapter.

    ```bash
    pip install "git+https://github.com/NousResearch/hermes-agent.git@1cec910b6a064d4e4821930be5cfaaf6145a2afd"
    ```
  </Step>
  <Step title="Install the kit">
    ```bash
    pip install -e .
    ```
  </Step>
  <Step title="Configure your environment">
    ```bash
    export OPENPASTURE_STORE=sqlite
    export OPENPASTURE_DATA_DIR="$HOME/.openpasture"
    export OPENPASTURE_BRIEF_TIME="06:00"
    export OPENPASTURE_COLLAR_GATEWAY=simulated
    ```

    See [Environment Variables](/environment-variables) for Alexandria and real
    collar settings.
  </Step>
</Steps>

## First farm

List the available tools:

```bash
openpasture tools list
```

Create a simple farm:

```bash
openpasture tool run setup_initial_farm --json '{"name":"Willow Creek","timezone":"America/Chicago","herd":{"id":"herd_1","species":"cattle","count":28},"paddocks":[{"id":"paddock_home","name":"Home","status":"grazing"}]}'
```

## First decision

Keep the herd on the default `propose` setting, so nothing is sent without you:

```bash
openpasture tool run set_autonomy --json '{"herd_id":"herd_1","autonomy":"propose"}'
```

Run one decision cycle for the herd:

```bash
openpasture tool run run_decision_cycle --json '{"herd_id":"herd_1"}'
```

The result is a `GrazingDecision`: `STAY`, `MOVE` to a specific boundary, or
`NEEDS_INFO`, with reasons, a confidence, and the one observation that would
help most. Under `propose` it waits for you.

Look at it, then answer it:

```bash
openpasture tool run list_decisions --json '{"herd_id":"herd_1"}'
openpasture tool run respond_to_decision --json '{"decision_id":"gd_...","response":"approve"}'
openpasture tool run get_boundary_status --json '{"decision_id":"gd_..."}'
```

Read it the way a farmer would:

```bash
openpasture tool run generate_morning_brief --json '{}'
```

Arguments shown are the common case. `openpasture tools list` prints each
tool's exact schema.
